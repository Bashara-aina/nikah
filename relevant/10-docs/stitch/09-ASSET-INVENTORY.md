## File Naming Convention for New Assets

When generating new assets from Stitch:

```
stitch-generated/{section}-{description}.{ext}

Examples:
stitch-generated/gate-floral-border.webp
stitch-generated/story-ch01-campus.webp
stitch-generated/japan-sakura-campus.webp
stitch-generated/closing-cats-peek.webp
stitch-generated/drapery-divider.webp
```

## Color Harmonization for Photographs

When placing `couple-standing-smiling-alt.jpg` in scrapbook context:

- Apply subtle warm tone (ivory/blush color grade)
- Do NOT alter faces, body proportions, or expressions
- Place in arch frame or with slight rotation
- Add washi-tape or pin accent at corner
- Shadow: warm `rgba(120,90,70,.10)` — never cool grey

When adapting cat reference photos to illustrations:

- Preserve distinguishing features (Moju's blue eyes, Jiro's amber eyes and red collar, Meng's asymmetric blaze, Hoshi's peeking pose)
- Render in watercolor-adjacent illustrated style matching hero-main
- Warm palette only — no cool tones
