# 05 — Copy & Tone
## Locked Copy, Voice Rules, All Section Text

**For Google Stitch designers.** All copy below is **locked**. Do not invent, paraphrase, or shorten. `{namaTamu}` = guest name from personal link. `{tanggal D-7}` = RSVP deadline (7 days before wedding).

---

## Voice Rules

| Rule | Detail |
|------|--------|
| **Heart language** | Indonesian for all body copy, greetings, story, event details |
| **English lift** | English only where romance elevates: hero headline, gate couple names |
| **No mixing** | Never Indonesian and English in the same sentence |
| **Tone** | Hangat, puitis, bercerita, sweet & sincere |
| **Story voice** | Third person for love story chapters |
| **Gift tone** | Public, grateful — never transactional or pushy |
| **Formality** | Warm-informal ("kamu"), never stiff ("Anda") except in FAQ answers |

### Typography per copy type

| Copy type | Font |
|-----------|------|
| Couple names, section titles | Cormorant Garamond |
| Body, labels, forms | Plus Jakarta Sans |
| Hashtag, gate names accent | Script accent (sparingly) |
