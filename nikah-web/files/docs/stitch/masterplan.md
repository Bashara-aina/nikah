
### 0.5 Critical override: Layer 0 is the envelope

The existing `stitch/04` and `GUIDE-02` open with a **storybook gate** (names visible) as the first thing. The user changed this on 2026-06-22:

> **Layer 0 must be an OPENING ENVELOPE before anything else** — before wedding title, before couple names, before guest name, before invitation text.

So the new front of the site is: **L0 Envelope → L1 Loading → L2 Gate → L3 Hero.** This matches `CURSOR-MASTER-BRIEF.md` ACT 0 (which always had the envelope), and now formally supersedes `stitch/04`'s "gate first" flow.

## 2. The 13 layers

### L0 — Opening Envelope (NEW)

**1. What the guest sees**
Ivory `#FBF7F0` paper filling the viewport. Centered: a hand-illustrated envelope in portrait orientation — ivory body with a triangular fold flap on top in dusty-blush `#F3D9D6`, thin botanical SVG line art at the bottom corners, a circular wax seal in the middle of the flap engraved with monogram "B&H" in warm amber `#C8922A`. The seal pulses gently (scale 1.0 ↔ 1.03, 2.5s yoyo). Below the envelope, a soft tap cue in Plus Jakarta Sans: **"Sentuh untuk membuka"**.

NO couple names. NO wedding title. NO guest name. NO invitation text. The envelope is the only thing on screen.

**2. What the guest does**
Taps anywhere on the envelope (or anywhere on the page — the whole envelope is the touch target). This is the **single most important interaction in the entire site** — it unlocks audio (La Vie en Rose), requests iOS gyroscope permission, and starts the ritual.

**3. Assets consumed**
- `assets/illustrations/envelope.svg` *(to create — inline SVG: body + flap + seal + botanical corners)* OR Tailwind + CSS only *(simpler v1)*

**4. Videos consumed**
None. The envelope is **Motion + CSS only**, not video.

**5. Motion spec** *(t ≈ 0.9s total handoff)*

```
t=0          Sealed envelope centered. Seal pulse loop (CSS @keyframes, 2.5s).
             Tap cue fade-in at t=200ms (opacity 0→1, 400ms ease-out).

t=tap        Button feedback on envelope (scale 0.97, 150ms ease-out)

t+0–300ms    Seal cracks open
             - scale 1.0 → 1.10
             - rotate 0° → 8°
             - opacity 1.0 → 0
             (Motion, ease.settle)

t+300–900ms  Envelope unfolds
             - flap lifts: clip-path inset() top edge, ease-out 400ms
             - sides fold back: 3D rotateY 0 → -25°, perspective 800px
             - paper bloom radial gradient fades in: opacity 0→0.6, 400ms

t+400–1200ms Audio: La Vie en Rose 0 → 30% (GSAP fade, 800ms)

t+400ms      iOS DeviceOrientationEvent.requestPermission() (inside tap gesture)

t+900ms      Hand off to L1 Loading (crossfade 400ms, ivory held)
             sessionStorage.setItem('nikah:envelope-opened', '1')
```

Ownership: **Motion** for entrance/transform; **GSAP** for audio fade; **CSS** for seal pulse + paper grain noise.

**Reduced motion:** Skip the entire animation. Set envelope to final open state for one frame, then crossfade to L1. Audio plays immediately at 30%.

**6. Components**
- ✅ New: `components/sections/Envelope.tsx` (client) — full component
- ✅ New: `components/sections/Envelope.module.css` (or co-located Tailwind) — pulse, paper grain, warm shadow
- ✅ Existing (scaffolded in `nikah-web/`): `app/page.tsx` will own the `phase: 'envelope' | 'loading' | 'gate' | 'opened'` state machine; `lib/motionTokens.ts` for the duration/ease values; `useGyro()` to request iOS permission

**7. stitch/10 screen:** *(new — not in `stitch/10`; will be Screen 0.5 in the next doc revision)*

**8. A11y + tier behavior**
- The whole envelope is the tap target (≥ 48×48px trivially satisfied; full viewport on mobile).
- `aria-label="Buka undangan"` on the envelope button.
- The "Sentuh untuk membuka" cue has `aria-live="polite"` so screen readers announce the action.
- `prefers-reduced-motion`: skip animation entirely. Instant handoff to L1.
- All tiers (HIGH/MID/LOW/REDUCED) see the same envelope — no tier differentiation for L0.

**9. Build gate**
- ✅ Envelope component exists and renders
- ✅ Tap unlocks audio + requests gyro permission
- ✅ Reduced motion fallback tested
- ⬜ Audio file `assets/audio/la-vie-en-rose.mp3` exists (compress only, not generated)

```
t=0.00  sky:           opacity 0→1, scale 1.06→1.00           (dur.enter)
t=0.15  meadow:        opacity 0→1, y +20→0                    (overlap)
t=0.45  couple:        opacity 0→1, y +40→0, scale .96→1      (ease.settle)
t=0.70  cats:          stagger.base — opacity + y +30→0 + scale .9→1
t=1.05  floralCorners: opacity 0→1, scale 1.08→1 from edges
t=1.20  doves:         MotionPath loop starts
t=1.25  butterflies:   fade + flutter starts
t=1.30  particles:     system activates
t=1.35  text:          per-line, opacity + y +12→0, stagger.base
t≈1.8   → STATE ALIVE. Hand off to parallax only.
```

**Post-assemble idle** (per `stitch/07` lines 60–68):
- Clouds: 12–16s horizontal drift (fal video owns; no GSAP duplication)
- Wildflowers: 4–6s gentle sway
- Doves: 8–10s arc drift
- Butterflies: 5–7s small figure-8
- 7 cats: 3–4s breathing — **randomized phase per cat, never synchronized**
- Grass: 6–8s slow wave

**Parallax** (per `stitch/07` §B.5 + `AGENTS.md`):
- Scroll parallax: 20px max offset, far layers slow, near layers fast
- Gyro tilt: `DeviceMotionEvent` + `gsap.quickTo()`, 0.6× scroll factor
- Single RAF for parallax + particles (per `docs/11 §9`)
- All `transform`/`opacity` only — never `top/left/width/height`

## 5. Master motion spec

### 5.1 Global timing reference (per `stitch/07` line 22)

| Motion | Duration | Easing |
|--------|----------|--------|
| Micro-interaction (button press) | 150ms | Quick ease-out |
| UI fade (gate dissolve, L0→L1) | 400–600ms | Soft ease-in-out |
| Section reveal on scroll | 700–1000ms | Gentle ease-out |
| Hero assemble | 1.4–1.8s | Staggered, organic |
| Ambient loop (sway, drift) | 3–8s | Sine-like, continuous |
| Text line reveal | 400ms per line | Fade + slight rise |
| Music fade-in | 800ms | Linear volume ramp |
| Envelope crack | 300ms | Motion ease.settle |
| Envelope unfold | 600ms | CSS clip-path ease-out |

### 5.2 L0 envelope → L1 loading → L2 gate → L3 hero handoff (full sequence)

```
t=0.000  L0: Sealed envelope centered, seal pulse (CSS @keyframes, 2.5s)
t=0.200  L0: Tap cue fades in (400ms ease-out)
t=TAP    L0: Envelope button feedback (150ms scale 0.97)
t=TAP+0  L0: iOS gyro permission request (must be in tap gesture)
t=TAP+0  L0: Audio La Vie en Rose 0→30% starts (800ms GSAP fade)
t=TAP+0  L0: Seal cracks (scale 1.0→1.10, rotate 0→8°, opacity 1→0, 300ms)
t=TAP+300  L0: Envelope flap lifts (clip-path 400ms) + sides fold (rotateY 0→-25°, 600ms)
t=TAP+400  L0: Paper bloom radial gradient (opacity 0→0.6, 400ms)
t=TAP+900  L0→L1: crossfade 400ms
t=TAP+1300 L1→L2: auto-advance 1.5s after L1 mount
t=TAP+2800 L2: Guest on gate
t=GATE    L2: "Buka Undangan" tap
t=GATE+0  L2: Button feedback 150ms
t=GATE+0  L2: Gate dissolves 600ms
t=GATE+800  L3: Hero assemble starts (1.8s timeline)
t=GATE+2600  L3: Hero text overlays appear
t=GATE+3000  L3: Sticky RSVP pill fades in
t=GATE+3100  AmbientLayer activates (particles, doves)
```

### 5.3 L3 hero 10-layer assemble (per `stitch/07` §Hero Assemble)

See L3 §5 above. Total ≈ 1.5s. All values from `lib/motionTokens.ts` via `lib/motionAdapter.ts`. No literal eases in components.

### 5.4 Post-assemble idle ownership table

| Element | fal video owns | GSAP/Motion adds | Never duplicate |
|---------|---------------|------------------|-----------------|
| Cloud drift | yes | — | — |
| Wildflower sway | yes | parallax 0.06 | — |
| Couple breathing | yes | parallax 0.12 | **no extra breathing** |
| Cat breathing/blink | yes | parallax 0.20–0.32 random per cat | **no extra breathing** |
| Corner florals | — | CSS rotate ±1.2° | — |
| Doves | — | MotionPath bezier | — |
| Butterflies | — | MotionPath + wing flutter | — |
| Particles | — | canvas RAF | — |

**Hard rule:** never add GSAP/Motion breathing on top of a fal video character.

### 5.5 Tier behavior (per `AGENTS.md`)

| Tier | Detection | Behavior |
|------|-----------|----------|
| HIGH | `deviceMemory ≥ 4` + `hardwareConcurrency ≥ 4` + no reduce | full motion, gyro, particles |
| MID | lower specs | no tilt, fewer particles |
| LOW | `deviceMemory < 2` or `saveData` | static poster, no video, no parallax |
| REDUCED | `prefers-reduced-motion: reduce` | instant, no positional motion, full content visible |

Per `stitch/08` §Motion Accessibility, REDUCED never hides content.

## 8. Performance, accessibility, and graceful degradation

### 8.1 Performance budget (per `AGENTS.md` + `REF-05`)

- Lighthouse mobile ≥ 90
- Hero LCP < 2.5s on throttled 3G
- Hero transfer < 800KB
- JS gz < 150KB
- Videos < 2MB each, max 1080px
- WebP for all images, AVIF where supported
- `next/image` for raster with explicit `width`/`height` (no CLS)
- Videos: `preload="none"` except hero, pause off-screen via `useVideoLayer`
- Single RAF for parallax + particles (per `docs/11 §9`)

### 8.2 Accessibility (per `stitch/08`)

- WCAG 2.2 AA target
- Body text contrast ≥ 4.5:1 (ink `#4A4039` on ivory `#FBF7F0` = 8.5:1 ✓)
- Large text ≥ 3:1
- All interactive elements ≥ 48×48px touch target, 8px gap
- Visible focus rings: 2px sage outline, 2px offset
- `aria-label` on icon-only buttons (copy, music, sticky RSVP, scroll-top)
- `aria-live="polite"` on countdown, form errors
- `prefers-reduced-motion`: instant, full content visible
- One `<h1>` per page (couple names on gate); sections use `<h2>`; story chapters use `<h2>`; FAQ uses `<h3>`
- Tab order matches visual reading order
- `<html lang="id">`
- Form fields have associated `<label>` elements
- Decorative illustrations: `aria-hidden="true"`
- Meaningful images: descriptive `alt` text
