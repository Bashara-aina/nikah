# 03 — Sections & Information Architecture
## What the Invitation Contains and In What Order

**For Google Stitch designers.** This is the complete section map — order, purpose, content hierarchy, and layout rhythm. One continuous scroll; no visible navigation.

---

## Emotional Arc

```
Ritual opening → Step into a living storybook world → Scroll through a love story → Feel warm → RSVP with joy
```

The invitation is one continuous scroll. No visible navigation bar. No chapters labeled as chapters. Just a world that unfolds as the guest moves through it — like turning pages in a book.

**Total journey time: approximately 1 minute.**

---

## Full Section Order (12 Sections)

```
0.  Loading Screen
        ↓
1.  Opening Gate (storybook cover — NOT envelope)
        ↓
2.  Hero — The Living Illustration
        ↓
3.  Welcome Message + Quran Verse
        ↓
4.  Countdown
        ↓
5.  Love Story (6 chapters + scrapbook gallery moments)
        ↓
6.  Japan Dream (Keio & SIT Tokyo)
        ↓
7.  Event Details (Venue, Map, Dress Code, Etiquette)
        ↓
8.  RSVP Form
        ↓
9.  Wishes Wall
        ↓
10. Gift / Tanda Kasih + FAQ
        ↓
11. Closing
```

Emotion first, practical details later. Guests can jump to RSVP anytime via the sticky button.

## Section-by-Section Guide

### 0. Loading Screen (1–2 seconds)

| | |
|---|---|
| **Purpose** | Tiny breathing room before the world opens |
| **Visual** | Small illustration — a sleeping cat inside a wreath of flowers. Soft, quiet. |
| **Text** | `#BASHicallyHANI's` only |
| **Behavior** | Advances automatically to the Gate. Never more than 2 seconds. No spinner. |

---

### 1. Opening Gate — Storybook Cover

| | |
|---|---|
| **Purpose** | The ritual moment — the guest "opens" the invitation |
| **Emotional note** | This is the **cover of the book**. It should feel precious. NOT an envelope. |
| **Visual** | Floral border frame surrounding the content (not a full-screen photo). Soft ivory `#FBF7F0` background. **No cats yet** — saved for hero reveal. |
| **Primary focus** | Guest's name displayed prominently in the center |
| **CTA** | `Buka Undangan` — sits in thumb-safe zone (bottom third) |

**On tap "Buka Undangan":**
1. **La Vie en Rose** begins fading in (low volume, loop)
2. Gate page dissolves → Hero assembles (1.4–1.8s)

### 2. Hero — The Living Illustration

| | |
|---|---|
| **Purpose** | The emotional "wow" moment. The world reveals itself. |
| **Emotional note** | First time the cats appear. The guest should smile here. |
| **Visual** | Full-screen layered scene based on `stitch/hero-main.png` |
| **Text (overlaid, appearing last)** | "We are getting married" · names · `22 · 08 · 2026` |

**Layer concept (back to front):**
- Background: soft morning sky with drifting clouds
- Mid: wildflower meadow (flowers gently sway)
- Subject: Hanifah (left, cream hijab) + Moju + Shiro. Bashara (right, navy) + Jiro + Meng.
- Foreground: Simba, Hoshi, Kimho in the grass
- Accents: floral corners, doves drifting across the sky

Everything in this scene is alive — **"hidup bukan kaku"** — nothing is completely still.

### 5. Love Story (6 Chapters)

| | |
|---|---|
| **Purpose** | Tell the love story in brief lines, not paragraphs. Third person. |
| **Emotional note** | Should feel like reading a children's book about two people. |
| **Layout** | Six chapters; illustration alternating left/right; 1–3 lines each |
| **Gallery** | Scrapbook photo moments woven between chapters — slight rotation, tape/pin accents, never a uniform grid |

**Chapters:**
1. **Awal yang Sederhana** — Meeting online via campus organization
2. **Antar Pulang, Hati Semakin Dekat** — Growing closer through campus life
3. **Bersama di Jakarta** — Working and studying together
4. **LDR, Sampai Tokyo** — Bashara at SIT Tokyo
5. **Setahun Kemudian, Hanifah Diterima di Keio** — Hanifah at Keio University, Hiyoshi
6. **Memutuskan Menikah, Studi Bersama** — Choosing to marry, study together in Japan

**Scrapbook gallery within story:**
- Real couple photos (e.g. `couple-standing-smiling-alt.jpg`) placed in arch frames
- Slight rotation (±2–4°), offset stacking, washi-tape or pin accents
- Photos appear as memory snapshots within the narrative — not a separate "gallery section"

## Reading Rhythm (Anti-Fatigue)

- Maks ~3–5 baris teks per blok; baris cerita pendek (lines, bukan paragraf)
- 1 ide per layar; whitespace generous; visual menyelingi teks
- Total ± 1 menit; user bisa lompat ke RSVP kapan saja
- Scrapbook photos break text rhythm — never more than 2 photos per story chapter
